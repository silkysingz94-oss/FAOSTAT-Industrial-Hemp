Methodology

The dashboard requests FAOSTAT QCL observations for the selected year. Hemp-related records are identified from the returned commodity/item descriptions. Values are grouped by country and statistical element. Country boundaries are displayed for geographic context only.

Countries without a matching reported observation are shown as no-data. Missing values are not interpreted as zero production.
